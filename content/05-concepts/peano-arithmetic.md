## Суть понятия
**Арифметика Пеано** — система аксиом, описывающая натуральные числа 0, 1, 2, … с помощью всего трёх исходных понятий: «ноль», «следующее число» (последователь) и «натуральное число». Её сформулировал [[giuseppe-peano|Джузеппе Пеано]] в 1889 году, опираясь на работу Рихарда Дедекинда (1888). Все остальные понятия арифметики — сложение, умножение, «больше», «простое число» — определяются через исходные.

## Пять постулатов простыми словами
1. **Ноль** — натуральное число.
2. **У каждого** натурального числа есть следующее, и оно тоже натуральное.
3. **Ноль не следует** ни за каким числом: ряд имеет начало.
4. **Разные числа** имеют разных последователей: два числа с одинаковым «следующим» совпадают.
5. **Индукция.** Если свойство верно для нуля и из того, что оно верно для числа, следует, что оно верно и для следующего, то оно верно для всех натуральных чисел.

Пятый постулат — ключевой: он «минует бесконечность» так же, как слово «все» в [[euclid-proof|доказательстве Евклида]]. Конечное правило охватывает бесконечно много чисел.

В современной логике под арифметикой Пеано (PA) обычно понимают систему *первого порядка*: к постулатам добавляют правила сложения и умножения, а индукцию записывают схемой — по отдельной аксиоме для каждого свойства, выразимого формулой.

## Роль в ГЭБ
- **Сердцевина теории чисел ([[chapter-04-consistency-completeness-and-geometry|Глава IV]]).** Хофштадтер спрашивает, одинакова ли теория чисел во всех возможных мирах, и отвечает: большинство математиков считают, что есть общая для всех теорий чисел «центральная теория», которая вместе с логикой входит во все возможные миры. Эта сердцевина и есть арифметика Пеано — аналог **абсолютной геометрии** (геометрии первых четырёх постулатов, общей для евклидовой и неевклидовых). См. [[possible-worlds-semantics|Семантика возможных миров]], [[euclid-fifth-postulate|Пятый постулат]].
- **Разветвление теории чисел.** Как геометрия ветвится, когда меняют пятый постулат, так теория чисел ветвится на стандартную и нестандартные. Это прямое следствие [[godel-incompleteness-theorem|теоремы Гёделя]]: есть утверждения, которые арифметика Пеано не может ни доказать, ни опровергнуть, и к ней можно добавить и само утверждение, и его отрицание. В отличие от геометрии, «сортов» теории чисел бесконечно много. Для практики они все совпадают: мосты одинаково стоят в любой из них.
- **ТТЧ ([[chapter-08-typographical-number-theory|Глава VIII]]).** Хофштадтер излагает постулаты Пеано и строит на их основе Типографскую Теорию Чисел (ТТЧ) — формальную систему, где теоремы выводятся по типографским правилам. ТТЧ по сути и есть арифметика Пеано первого порядка, записанная символами. Именно о ней доказывается неполнота в [[chapter-14-on-formally-undecidable-propositions-of-tnt-and-related-systems|Главе XIV]].

## Связь с другими карточками
- **Законы арифметики.** Коммутативность и ассоциативность, которые в Главе II «просто понимаются», в арифметике Пеано становятся теоремами: их доказывают индукцией. См. [[laws-of-arithmetic|Основные законы арифметики]].
- **Рекурсия.** Сложение и умножение определяются рекурсивно: x + 0 = x, x + следующее(y) = следующее(x + y). См. [[recursion|Рекурсивность]].
- **Непротиворечивость.** По второй теореме Гёделя арифметика Пеано не может доказать собственную непротиворечивость своими средствами (в 1936 году Генцен доказал её, выйдя за пределы системы).

## Комментарий составителя
Пеано начинал натуральный ряд с единицы; современное изложение (и ТТЧ у Хофштадтера) — с нуля. Даты (Дедекинд 1888, Пеано 1889, Генцен 1936) и формулировка про первый порядок даны по памяти; изложение постулатов в Главе VIII стоит сверить с текстом при подготовке той встречи.
